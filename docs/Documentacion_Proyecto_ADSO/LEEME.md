# Paquete documental ADSO de MEVIPLAST

Documentos del proyecto elaborados sobre las plantillas institucionales del SENA (ADSO), en su versión vigente. El índice oficial, con el código, la versión, el estado y el responsable de cada documento, es [`00_Gobierno_Documental/Indice_Maestro.xlsx`](00_Gobierno_Documental/Indice_Maestro.xlsx).

| Carpeta | Contenido |
| --- | --- |
| [`00_Gobierno_Documental`](00_Gobierno_Documental) | Guía de arquitectura documental del instructor e Índice Maestro |
| [`01_Inicio_y_Planeacion`](01_Inicio_y_Planeacion) | Formulación y constitución; gestión del proyecto |
| [`02_Requisitos`](02_Requisitos) | Alcance y requisitos; backlog, historias y casos de uso; matriz de trazabilidad; diagramas |
| [`03_Diseno`](03_Diseno) | Arquitectura, datos y diseño técnico; diseño UX/UI y capturas |
| [`04_Calidad`](04_Calidad) | Plan de calidad, pruebas y aceptación; acta de aceptación por rol |
| [`05_Manuales`](05_Manuales) | Manual técnico y de operación; manual de usuario |
| [`06_Cierre`](06_Cierre) | Informe de cierre y entrega |
| [`07_Evaluacion`](07_Evaluacion) | Guía de sustentación, lista de chequeo final y rúbrica |
| [`08_Repositorio`](08_Repositorio) | Guía de estructura y evidencias del repositorio |

Los Word y Excel no se ven dentro de GitHub: usa **Download raw file** en cada archivo, o descarga el repositorio completo. La documentación técnica en Markdown (API, pruebas, evidencias y decisiones) está en el resto de la carpeta [`docs/`](..).

Estos documentos se actualizan junto con el código; cada cambio queda en su control de versiones y en el historial de Git.
