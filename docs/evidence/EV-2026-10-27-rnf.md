## EV-2026-10-27-07 · RNF-007 Compatibilidad

Comando: `npm run test:browser --prefix backend` (`backend/tests/browser/navegadores.browser.js`), con `playwright-core` 1.64.0.

| Navegador | Versión | Origen |
| --- | --- | --- |
| Microsoft Edge | 156.0.4314.42 | Instalado en el equipo (canal estable) |
| Google Chrome | 156.0.8078.4 | Chrome for Testing, la compilación oficial de Google para pruebas automáticas |
| Mozilla Firefox | 157.0 | Compilación de Playwright para pruebas automáticas, no el instalador oficial de Mozilla |

Los 10 flujos críticos se ejecutaron en cada navegador. Cada flujo falla si aparece un error de JavaScript en la página o una respuesta de error de la API no esperada.

1. Sitio público y mensaje de inicio de sesión fallido.
2. Inicio de sesión, todas las vistas del rol y cierre de sesión (un flujo por cada uno de los cinco roles).
3. Vendedor: registrar una venta y ver el comprobante.
4. Operario: registrar un avance de producción.
5. Almacenista: registrar un ingreso de inventario.
6. Administrador: abrir el reporte de ventas y descargar el Excel.

Resultado: **30 de 30 flujos sin bloqueo** (10 por navegador). Umbral: 100 %. **Cumple.**

Límites: el requisito pide las dos últimas versiones de cada navegador; se probó la última. Firefox se probó con la compilación de Playwright. Conviene repetir la prueba manualmente con el Firefox oficial y en los equipos de MEVIPLAST.
