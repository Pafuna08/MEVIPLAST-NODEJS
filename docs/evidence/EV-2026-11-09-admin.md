# Evidencia de la protección del administrador (2026-11-09)

- Ambiente: Windows 11, Node.js 22.21.0, MariaDB 10.4.32 (XAMPP). Bases desechables `meviplast_afinado` (sondeo), `meviplast_e2e` y `meviplast_browser`.
- Código: rama `fix/MEVI-69-proteger-administrador`, sobre `develop` (`c23c603`).
- Origen: sondeo de casos límite contra la API, hecho por el equipo en la tercera ronda de afinado.
- Responsable de la ejecución: Pablo E. Fuenmayor Osuna, con asistencia de Claude Code.

## EV-2026-11-09-06 · DEF-021 · CP-089

| Paso | Antes | Después |
| --- | --- | --- |
| El administrador se cambia su propio rol a «operario» (`PUT /api/usuarios/{id}`) | 200: el sistema quedó sin administrador | 400 «No puedes quitarte el rol de administrador»; la base no cambia |
| El administrador se desactiva (`activo: 0`) | 200: no pudo volver a entrar | 400 «No puedes desactivar tu propia cuenta» |
| El administrador elimina su propia cuenta (`DELETE /api/usuarios/{id}`) | Solo lo impedía el panel, no la API | 400 «No puedes eliminar tu propia cuenta» |
| Un administrador desactiva a otro administrador | 200 | 200 (sigue permitido) |
| Tabla de usuarios del panel | «Desactivar» también en la fila propia | La fila propia muestra «Tu cuenta», sin «Desactivar» ni «Eliminar» |

El servicio revisa en una transacción, con bloqueo de filas, que siempre quede al menos un administrador activo, para que dos cambios simultáneos no dejen el sistema sin administrador.
